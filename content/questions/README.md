# Формат файлів з питаннями

Кожен `*.txt` у цій теці — набір питань. Порожні рядки та рядки з `//` ігноруються.

```
@ s16                                   ← тема для наступних питань (s1…s34 — розділи, g1…g7 — групи знаків, mk, safe, med)
Q: Текст українською || Текст по-русски
I: {"scene": {...}}                     ← необов'язково: схема (див. app/js/scene.js), {"sign":"2.1"}, {"signs":["2.3","7.8"]}, {"mark":"1.1"}
- Неправильна відповідь || Неправильный ответ
~ Чому вона неправильна || Почему он неправильный   ← необов'язково, одразу після «-»
+ Правильна відповідь || Правильный ответ   ← рівно одна з «+»
E: Пояснення || Объяснение
R: 16.11 16.12                          ← пункти Правил
```

У текстах можна посилатися на знаки `{s:2.1}`, розмітку `{m:1.12}` і пункти `{p:16.12}`.
Ідентифікатор питання обчислюється з тексту, тому після зміни формулювання прогрес за ним скидається.

Зібрати дані застосунку: `python tools/build.py`.
