# ПДР України — подготовка к экзамену на права (категория B)

Офлайн‑приложение с полным текстом Правил дорожного движения Украины на украинском и русском языках,
всеми дорожными знаками, разметкой, объяснениями, тестами и пробным экзаменом, как в сервисном центре МВД.

> В папке [`psy/`](psy/README.md) лежит второе приложение того же формата — «Психопрофиль»: тест характера и совместимости для нескольких человек.

## Что внутри

- **Правила** — все 34 раздела (294 пункта) по редакции на 01.10.2026, переключатель UA/RU, поиск, избранные пункты.
  Знаки и разметка в тексте кликабельны: нажмите на номер, откроется карточка.
- **Пояснения** — к каждому разделу короткая выжимка «простыми словами».
- **Знаки** — 368 знаков в 7 группах с картинками, описанием из раздела 33 и ссылками на пункты, где они упоминаются.
- **Разметка** — 65 видов горизонтальной и вертикальной разметки со схемами.
- **Тесты** — около 930 вопросов: 238 авторских вопросов по разделам Правил (со схемами перекрёстков и пояснениями),
  вопросы по каждому знаку и виду разметки, темы «Безопасное вождение» и «Домедицинская помощь».
- **Экзамен** — 20 вопросов, 20 минут, не больше 2 ошибок; по желанию экзамен прекращается после 3‑й ошибки; история попыток.
- **Ошибки, избранное, статистика** — прогресс сохраняется на устройстве.

## Запуск на Windows

Запустите `dist\ПДР України.exe`. Установка не нужна, интернет не нужен. Прогресс хранится в `%APPDATA%\PDR-Ukraine`.

Пересобрать `.exe` (например, после правки вопросов):

```powershell
powershell -ExecutionPolicy Bypass -File desktop\build_exe.ps1
```

Скрипт сам поставит `pywebview` и `pyinstaller` в `desktop\.venv`. Нужен Python 3.10+.
Окно работает на движке Microsoft Edge WebView2, который в Windows 10/11 уже установлен.

## iPhone и iPad (без App Store)

Приложение — это PWA, оно опубликовано на GitHub Pages: **https://iioverlordii.github.io/pdr-ukraine/**

На iPhone откройте эту ссылку в **Safari** → кнопка «Поделиться» → **«На экран „Домой“»**.
Приложение будет открываться как обычное, на весь экран, и после первого запуска работать без интернета.
Так же его можно установить на Android (Chrome → «Установить приложение») и на компьютер (Edge/Chrome → «Установить»).

## Как устроен проект

```
app/            само приложение (то, что публикуется и попадает в .exe)
  index.html, css/, js/       интерфейс: app.js — экраны и тесты, scene.js — схемы перекрёстков, marking-draw.js — разметка
  data/*.js                   данные, генерируются tools/build.py — руками не править
  img/signs/                  картинки знаков
content/        исходники контента
  pdr_uk.json                 текст ПДР (украинский), разобранный по пунктам
  ru/rules_NN.txt             русский перевод раздела NN (строка = блок текста)
  ru/sign_names.txt           русские названия знаков
  explain.txt                 пояснения к разделам
  marking.txt                 короткие названия разметки
  questions/*.txt             вопросы (формат — в questions/README.md)
tools/
  build.py                    собирает content/ → app/data/ и офлайн‑кэш (sw.js)
  parse_pdr.py                разбор HTML‑страниц ПДР в content/pdr_uk.json
  fetch_signs.py              загрузка картинок знаков с Wikimedia Commons
desktop/        оболочка для Windows (main.py, build_exe.ps1, icon.ico)
```

Добавить или исправить вопрос: отредактируйте файл в `content/questions/`, затем выполните

```bash
python tools/build.py
```

Скрипт проверит формат, ссылки на пункты и знаки и сообщит об ошибках.

Опубликовать изменения на сайт (ветка `gh-pages` содержит только папку `app`):

```bash
git add -A && git commit -m "Обновление вопросов" && git push && git subtree push --prefix app origin gh-pages
```

Установленное на телефоне приложение подтянет новую версию при следующем запуске с интернетом.
Чтобы посмотреть результат в браузере: `python -m http.server 8765 --directory app` → http://127.0.0.1:8765.

## Источники и оговорки

- Текст Правил — постановление КМУ № 1306 от 10.10.2001 (официальный документ, редакция на 01.10.2026; текст получен с vodiy.ua без комментариев сайта).
  Русский текст — перевод для удобства, официальный текст — украинский. Сверяйтесь с https://zakon.rada.gov.ua.
- Изображения знаков — Wikimedia Commons (общественное достояние), миниатюры 330 px.
- Схемы разметки и перекрёстков нарисованы для этого приложения.
- Вопросы и объяснения составлены для обучения и не являются официальной базой вопросов ГСЦ МВД.
