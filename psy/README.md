# Психопрофиль — тест характера и совместимости

Офлайн‑приложение (PWA + .exe для Windows), устроенное так же, как «ПДР України».
Несколько человек проходят анкету по очереди на одном устройстве или каждый на своём телефоне.
На выходе: профиль каждого, совместимость и схожесть пар, матрица и портрет группы.

## Что измеряется

| Блок | Модель | Вопросов |
|---|---|---|
| Характер (обязательный) | Большая пятёрка: 5 факторов и 10 аспектов (ДеЯнг) + честность‑скромность (HEXACO) | 44 |
| Близость | Привязанность: тревога и избегание → 4 стиля (Бартоломью; Бреннан, Кларк, Шейвер) | 12 |
| Ценности | 10 базовых ценностей Шварца | 20 |
| Мораль | Моральные основания Хайдта (6) | 12 |
| Мышление | Анализ и интуиция (Эпштейн, Канеман), потребность в определённости (Круглански), установка на рост (Двек), чувствительность (Арон), хронотип | 18 |
| Конфликты | 5 стилей (Томас–Килманн) + «четыре всадника» Готтмана | 14 |
| Забота | «Языки любви» Чепмена (с оговоркой о слабой научной базе) | 10 |

Полный тест — 130 вопросов, около 15 минут; быстрый (характер + близость) — 56 вопросов, около 6 минут.

**Профиль человека:** Большая пятёрка с аспектами, тип из 16 (выводится из Большой пятёрки по Маккрае и Косте, 1989),
темперамент (по Айзенку), стиль привязанности, круг ценностей, моральный профиль, тип мышления и хронотип,
стиль в конфликтах, «язык заботы», роль в команде.

**Пара:** совместимость и схожесть отдельно, в трёх контекстах (пара / дружба / работа), разложение по компонентам,
сильные стороны, зоны трения, советы, сравнение профилей.
**Группа (3+):** матрица совместимости и схожести, самые гармоничные, самые похожие и самые разные пары, портрет группы, покрытие ролей.

Раздел «Теория» описывает каждую модель: на чём она основана, насколько она подтверждена исследованиями и какие книги почитать.
Там же сказано, что не вошло в тест и почему (акцентуации, эннеаграмма, соционика, стили обучения).

## Как пользоваться вдвоём или группой

- **На одном устройстве:** «Новый участник» → тест → «Следующий участник» → … → «Сравнить всех».
- **На разных устройствах:** в профиле нажмите «Поделиться». Это даёт ссылку (если приложение открыто с сайта) или код вида `Аня: AQKH…`.
  Второй человек вставляет его в «Добавить по коду или ссылке». Можно вставить сразу несколько строк.
  В код попадают только ответы и имя; сервера нет, всё хранится на устройстве.

## Запуск

```bash
python -m http.server 8766 --directory psy/app     # http://127.0.0.1:8766
```

**Windows (.exe):** `powershell -ExecutionPolicy Bypass -File psy\desktop\build_exe.ps1` → `psy\dist\Психопрофиль.exe`.
Ответы хранятся в `%APPDATA%\Psy-Profile`.

**iPhone/Android:** приложение нужно опубликовать на любом статическом хостинге с https, например на GitHub Pages
в отдельном репозитории:

```bash
git remote add psy https://github.com/<user>/psy-profile.git
git subtree push --prefix psy/app psy gh-pages
```

Затем откройте ссылку в Safari → «Поделиться» → «На экран „Домой“». После первого запуска приложение работает без интернета.

## Структура

```
psy/
  app/                 то, что публикуется и попадает в .exe
    js/data.js         модули, вопросы, шкалы, тексты результатов, «Теория» (правится руками)
    js/engine.js       подсчёт баллов, типы, код для обмена, формулы совместимости (без DOM)
    js/app.js          интерфейс: анкета, отчёты, сравнение, импорт
  tools/build.py       проверяет data.js и обновляет офлайн‑кэш (sw.js) и ?v= в index.html
  tools/make_icons.py  рисует PNG‑иконки и icon.ico (нужен Pillow)
  desktop/             оболочка для Windows (pywebview)
  test/engine.test.js  тесты движка: node --test psy/test/engine.test.js
```

После любой правки в `app/` выполните `python psy/tools/build.py`.

**Важно:** порядок элементов `items` и `modules` в `data.js` задаёт формат кода для обмена.
Существующие вопросы не переставляйте и не удаляйте, новые добавляйте только в конец.

## Оговорки

- Вопросы о чертах личности адаптированы из International Personality Item Pool (общественное достояние);
  остальные вопросы составлены для приложения по описаниям моделей. Это не официальные методики (NEO‑PI‑R, MBTI®, ECR‑R, PVQ, MFQ, TKI).
- Нормы для перевода в шкалу 0–100 приблизительные: результаты показывают положение относительно «среднего человека», а не клинические процентили.
- Совместимость — повод для разговора, а не прогноз. Исследования (Joel et al., 2020) показывают, что качество отношений
  слабо предсказывается сходством черт и сильнее — личной устойчивостью, привязанностью и поведением в конфликтах.
  Поэтому формула весит именно эти компоненты.
